  Le Pay-Per-Click (PPC) est un modèle de publicité où l'annonceur paie à chaque fois qu'un internaute clique sur sa publicité. Sur Google Ad

1.2 Structure d'un compte Google Ads
  Compte : Contient les informations de facturation et les utilisateurs.

  Campagne : Organisée autour d'un objectif spécifique (ex: Trafic, Ventes) et d'un budget.

  Campagne Vidéo : Publicités vidéo sur YouTube.

Cours 2 : Recherche de Mots-Clés et Ciblage



Objectifs d'apprentissage

  · Utiliser le Planificateur de mots-clés
  · Comprendre les différents types de correspondance (Broad, Phrase, Exact)
  · Construire une liste de mots-clés pertinents



2.1 Le Planificateur de mots-clés (Keyword Planner)
  C'est l'outil gratuit de Google pour trouver des mots-clés et estimer leur potentiel.

  Volume de recherche mensuel : Le nombre moyen de recherches par mois.

  Concurrence : Le nombre d'annonceurs qui font des enchères sur ce mot-clé.

  Enchère suggérée : Le coût par clic (CPC) estimé pour apparaître en première page.

2.2 Types de correspondance
  Correspondance large (Broad Match) : L'annonce peut apparaître pour des requêtes liées.

  Correspondance d'expression (Phrase Match) : L'annonce apparaît si la requête contient l'ordre exact des mots du mot-clé.

  Correspondance exacte (Exact Match) : L'annonce n'apparaît que si la requête est identique ou très proche du mot-clé.

3.2 Stratégies d'enchères

       1.1 Comment Fonctionne Google
       Le fonctionnement de Google repose sur 3 étapes :

       1. Crawl (Exploration) : Les robots Google (Googlebot) parcourent le web en suivant les liens
       2. Indexation : Les pages découvertes sont stockées dans l'index de Google
       3. Classement (Ranking) : L'algorithme classe les pages selon plus de 200 facteurs

1.3 Les Facteurs de Classement Principaux

3.1 Les Éléments Techniques Essentiels
    Vitesse de chargement : Objectif < 3 secondes (outil : PageSpeed Insights, GTmetrix)
    HTTPS : Certificat SSL obligatoire (sécurité et confiance)
    Responsive design : Site adapté à tous les écrans
    Schema markup : Données structurées (avis, produits, FAQ)
    Sitemap XML : Fichier listant toutes les pages du site
    Robots.txt : Guide les robots d'exploration
    URL canoniques : Éviter le contenu dupliqué

  Cours 6 : Local SEO et Google Business Profile                        3h



    Objectifs d'apprentissage
        Configurer et optimiser Google Business Profile
        Maîtriser le référencement local

6.1 Google Business Profile (GBP)
Google Business Profile (anciennement Google My Business) est essentiel pour toute entreprise
locale. C'est la fiche qui apparaît sur Google Maps et dans les résultats locaux.

6.2 Optimisation de la Fiche
1. Catégorie principale : Choisir la catégorie la plus précise
2. Description : 750 caractères avec mots-clés locaux
3. Heures d'ouverture : À jour, y compris jours fériés
4. Photos : Extérieur, intérieur, produits, équipe (min. 10 photos)
5. Services/Produits : Liste détaillée avec descriptions
6. Posts réguliers : Offres, actualités, événements (1-2/semaine)
